01 — ҚЫСҚАША ҚАЙТАЛАУ

Дәреже дегеніміз не?

Бірдей көбейткіштерді көбейтуді ықшам жазудың жолы.

01ДӘРЕЖЕ

an = a · a · … · a

a — негіз, n — дәреже көрсеткіші. Негізді n рет көбейтеміз.

34 = 3 · 3 · 3 · 3 = 81
02КӨБЕЙТУ

am · an = am+n

Негіздері бірдей дәрежелерді көбейткенде көрсеткіштері қосылады.

23 · 22 = 25
03ДӘРЕЖЕЛЕУ

(am)n = am·n

Дәрежені дәрежеге шығарғанда көрсеткіштер көбейтіледі.

(52)3 = 56
